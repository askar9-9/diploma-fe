# Spec: Mosquitto MQTT Broker Configuration

## Назначение

Mosquitto — MQTT-брокер, обеспечивающий асинхронный обмен сообщениями между Device Simulator и Backend. Является единственным компонентом системы, развёрнутым из готового Docker-образа без кастомной логики.

## Контракт

Конфигурационный файл: `infra/mosquitto/config/mosquitto.conf`

Параметры конфигурации:
- `listener 1883` — прослушивает порт 1883 (стандартный MQTT-порт)
- `allow_anonymous true` — анонимный доступ (демонстрационная среда, без аутентификации)
- `persistence true` — хранение retain-сообщений между перезапусками
- `persistence_location /mosquitto/data/` — директория для хранения данных
- `log_dest stdout` — логирование в stdout (для отладки через `docker-compose logs`)

## Acceptance Tests

### Given / When / Then

**Тест 1: Конфигурационный файл существует**
- Given: смонтирован volume `./infra/mosquitto/config:/mosquitto/config`
- When: брокер Mosquitto стартует
- Then: брокер читает конфигурационный файл без ошибок

**Тест 2: Анонимный доступ**
- Given: запущен Mosquitto с данной конфигурацией
- When: клиент подключается без логина/пароля
- Then: подключение принято (код ответа 0)

**Тест 3: Прослушивание порта 1883**
- Given: запущен Mosquitto
- When: клиент пытается подключиться к порту 1883
- Then: соединение устанавливается успешно

**Тест 4: Retain-сообщения**
- Given: клиент опубликовал retain-сообщение в топик `homeiq/devices/motion_hall/state`
- When: новый клиент подписывается на этот топик
- Then: новый клиент немедленно получает последнее сохранённое сообщение

**Тест 5: Логирование**
- Given: включён `log_dest stdout`
- When: клиент подключается/отключается
- Then: события подключения отображаются в stdout контейнера
